# Drogaria Triunfo: Cuidado Digital

Site institucional e e-commerce da **Drogaria Triunfo de Serrana — SP**.

## Sobre

Plataforma digital para compra de medicamentos, dermocosméticos, vitaminas e produtos de higiene com entrega em Serrana - SP.

- **Matriz:** Rua Vicente de Paula Lima, 1545
- **Filial 01:** Rua Deolinda Rosa, 1068

## Desenvolvimento Local

Você precisa de Node.js e npm instalados.

```sh
git clone <this-repository-url>
cd drogaria-triunfo-cuidado-digital-main
npm install
npm run dev
```

## Stack

- React 19 + TypeScript
- TanStack Router + TanStack Start
- Tailwind CSS v4
- Radix UI + shadcn/ui
